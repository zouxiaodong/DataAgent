布局设计方案

当前系统包含 5 个核心页面，需要全新设计布局结构

当前页面清单

  • 📋 /agents — 智能体列表（卡片网格）
  • ➕ /agent/create — 创建智能体（表单向导）
  • 📄 /agent/:id — 智能体详情（配置面板）
  • 💬 /agent/:id/run — 运行界面（聊天对话 + 图表）
  • ⚙️ /model-config — 模型配置（数据表格）

布局方案选择

你希望采用哪种整体布局模式？

A

左侧导航栏 + 主内容区

固定左侧垂直导航（图标+文字），右侧大面积内容区。类似 Slack、Discord、VS Code 的布局

B

顶部导航 + 全屏内容

顶部水平导航栏，下方全屏内容区域。类似 GitHub、Vercel Dashboard 的布局

C

无边框沉浸式

无传统导航栏，通过首页卡片直接进入各功能模块，每个页面独立设计。类似 Apple 产品页风格
